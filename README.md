# vthquanh.github.io

Personal academic website of **Vo Thi Hoang Quanh** (Võ Thị Hoàng Quanh) — https://vthquanh.github.io

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme, deployed to GitHub Pages by `.github/workflows/deploy.yml`.

## Where to edit

| What | File |
| --- | --- |
| Bio, profile photo, highlight box | `_pages/about.md`, `assets/img/prof_pic.jpg` |
| News | `_news/*.md` (one file per item) |
| Publications | `_bibliography/papers.bib` (`selected = {true}` shows on the home page) |
| Research projects | `_projects/*.md` |
| Teaching | `_pages/teaching.md` |
| CV PDF | `assets/pdf/Vo_Thi_Hoang_Quanh_CV.pdf` |
| Social links | `_data/socials.yml` |
| Site settings, SEO | `_config.yml` |

Every push to `main` rebuilds the site automatically.
